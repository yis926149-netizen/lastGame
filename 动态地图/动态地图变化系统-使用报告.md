| 项 | 结论 |

**回答原问题**：三层解耦成立——逻辑层（`MapMutationService`）、渲染层（`IMapRenderBackend`/`ChunkMapRenderer`）、动画层（`MapVisualTransitionService`）是三个独立服务，经 Zenject 注入串联。**换动画参数只改一处（`MapTransitionOptions`）；换错峰模式改一处（`ComputeStaggerDelays` 加分支）；换动画"表现类型"需改两处半（UV2/UV3 生成 + Transition Shader，详见 §五）**，且都不涉及调用方与事务协议。

## 三、标准使用流程（调用方模板）

### 3.1 一次地块变化（最小编程面）

```csharp
// 注入：MapMutationService、TemporaryVisibilityService（可选）、HexHighlightRenderer（可选）

_mutationService.BeginTransaction();                      // 嵌套调用抛 InvalidOperationException

_mutationService.Apply(cell, new HexCellPatch
{
    HasHeight = true,  Height = 5f,                       // 只填要改的字段
    HasMovementCost = true,  MovementCost = 1f,
    HasIsUnexplorable = true,  IsUnexplorable = true,
    ClearRiver = true,  ClearLandForm = true,  ClearResource = true,
    // Owner = 1;   // 归属走 LogisticsService 领域入口（>=0 设置，<0 清除）
});

_mutationService.Commit(new MapTransitionOptions
{
    Duration = 1.2f,                                      // 0 = 同步提交（无动画）
    Stagger = MapTransitionStagger.CenterToOuter,         // 仅 Simultaneous/CenterToOuter 已实现
    StaggerCenter = centerCell,
    Easing = null,                                        // null = smoothstep
    LockAffectedCells = true                              // 动画期间锁格
});
```

Commit 内部自动完成（MapMutationService.cs:169-244）：写数据 → 水陆双向重置 → `CancelMovesIntersecting` + `EjectUnitsFromImpassableCells`（弹射）→ 脏 Chunk staging → mesh/Collider 交换 → 单位吸附 → 对象/浮标刷新 → Brain 路径失效 → `MapVisualEventSO.Raise()`（一次）→ `MapChanged` 事件 → 动画启动或同步 Finalize。

### 3.2 事件订阅

```csharp
_mutationService.MapChanged += OnMapChanged;
void OnMapChanged(MapChangedEvent e)   // CommitId / ChangedCells / DirtyFlags / Phase / AffectedChunks
{
    if (e.Phase == MapChangedPhase.Committed)  { /* 读新状态 */ }
    if (e.Phase == MapChangedPhase.TransitionStarted) { /* 动画开始 */ }
    if (e.Phase == MapChangedPhase.Finalized) { /* 动画完成、锁已释放 */ }
    if (e.Phase == MapChangedPhase.Cancelled) { /* 被后续提交强制完成 */ }
}
```

### 3.3 临时点亮迷雾（来源式，多来源互不影响）

```csharp
_lease = _visibilityService.AcquireLease("Arena", cells);  // 同一来源可持多份
// 突起帧瞬间点亮（突破 20fps 限频）：
_renderBackend.ForceRefreshFogVisuals(cells);              // null = 全量渐变刷新
// 结束时（含异常/对局结束 finally）：
_lease.Release();  _renderBackend.ForceRefreshFogVisuals();
```

### 3.4 动画期间让对象跟随地形升起

```csharp
_visualTransition.RegisterVisualFollower(chest.transform, centerCell);
_visualTransition.UnregisterVisualFollower(chest.transform);  // 结束/销毁前必调
```

### 3.5 分帧提交（大数据量防卡顿）

```csharp
_mutationService.CommitSliced(null, maxChunksPerFrame: 2);   // 每帧最多构建 2 个 Chunk
// 不支持动画：Duration>0 会被强制改 0 并警告
```

### 3.6 诊断

```csharp
MapMutationDiagnostics.EnableCommitLogging = true;           // Commit 摘要日志
MapMutationDiagnostics.EnableDirtyChunkHighlight = true;     // 脏格品红高亮
_mutationService.ClearDirtyChunkHighlight();
```

## 四、动画机制要点（阶段四/五，2026-08-05 波浪测试反哺修订）

- **通道**：UV2.x=startVertexY、UV2.y=targetVertexY、UV3.x=delayStart、UV3.y=delayEnd（每格动画窗口=end−start；Wave 行窗口经保留键 `RiseWindowKey=-1` 传递）。**2026-08-05 起顶点插值在 CPU 侧执行**（`SetChunkAnimationProgress` 每帧写 `mesh.vertices`）；Shader vert 读 UV 通道不可靠（surface shader 编译行为，实机三次实验确认），`_Transition` Shader 的 vert 已移除变形。
- **驱动**：`MapVisualTransitionService.Tick` 每帧把 eased 进度（C# 端只做一次 smoothstep）传给后端 CPU 顶点动画；非脉冲动画仍同步写 `MaterialPropertyBlock._ChunkProgress` 供 surf/ShadowCaster 的 keep-below clip 使用。
- **错峰公式**：`(p − delayStart)/(delayEnd − delayStart)`，**禁止回退 `(1−delay)` 归一化**（早动格占满整个时间线、传播前沿不可控——实机"曲面"观感；波浪测试第三次修订）。
- **顶出方案**：提交前克隆旧 Terrain mesh 为 `TerrainGhost`（下沉 0.02）；Transition Shader 用 `_ChunkAnimBaseY + _ChunkProgress*_ChunkAnimRiseHeight` 做 keep-below clip（`clip(animClipY - worldPos.y + 0.02)`），progress=0 新平台整体隐藏，随进度从旧地表下逐层顶出；手写 ShadowCaster pass 与 surf 同一 clip（修"隐形黑块"）。
- **材质切换**：动画期间 Terrain 换 `*_Transition` 变体（缓存共享），Finalize 恢复稳定材质（ChunkMapRenderer.cs:390-398/527-555）。**纯视觉脉冲（`AnimationReturnsToStart`）旁路**：不提交 staging mesh、不换材质、不写 MPB/clip——仅提取 targetY/delay 在当前稳定 mesh 上原地动画（方案 §二十二，否则 UV0/法线/submesh/材质槽被替换导致"动画中地图变色"）。
- **首帧约束**：任何动画 staging 提交 Renderer 前先把顶点写为旧高度（`ApplyAnimationStartVertices`）——目标网格先可见一帧即"全图突变"。
- **旧视觉基线**：高度类拓扑不变动画 = 当前显示 mesh 逐顶点快照（`BindWaveStartVerticesFromActiveMesh`），禁止数据模型差值反推。
- **水面/河流淡出**：`CaptureFadeGhosts` 克隆旧 mesh 挂 `_FadeAlpha` MPB，alpha=1-progress，Finalize 销毁（含克隆 mesh）。
- **外围网格跟随**：FogConnector 等贴地静态网格经 `GetAnimatedWorldY(cell)` 跟随（FogManager.LateUpdate），禁止直接读 `RealCenterWorldCoordinate` 当视觉高度。
- **并行动画（阶段五）**：新动画只强制完成相交 Chunk 的旧动画；Finalize 只 `UnlockCells` 自己的格（互不清锁）。
- **对局结束兜底**：`ForceComplete()` / `ForceCompleteSliced()` 由 `ArenaEventManager.Shutdown()` 调用。

## 五、结论：换不同动画要改哪里（代码事实）

| 要换的东西 | 改动位置 | 数量 |
|---|---|---|
| 时长/缓动/中心格/是否锁格 | `MapTransitionOptions`（调用处） | **1 处** |
| 错峰模式（已预留 OuterToCenter/Random/Directional/Wave） | `MapVisualTransitionService.ComputeStaggerDelays`（MapVisualTransitionService.cs:97-138）加分支 | 1 处 |
| 动画"表现类型"（如洪水侧推/溶解） | ① `ChunkMapRenderer` 的 UV2/UV3 填充（`AppendRectAnimUV`/`AppendTriangleAnimUV` 等）② CPU 顶点动画公式（`SetChunkAnimationProgress`；非高度型表现需新插值维度时扩展 UV 通道）③（如需新驱动方式）`MapVisualTransitionService.Tick` | 2~3 处 |
| 脉冲型纯视觉特效（升起→回落、不改逻辑终态） | `MapTransitionOptions.Stagger=Wave` + 调用方在 Commit 后立即恢复逻辑数据（参照 `MapWaveTestController` 模式）；`AnimationReturnsToStart` 自动启用原地脉冲路径 | 1 处（调用方） |
| 完全不想要动画 | 不注入 `MapVisualTransitionService`，或后端 `SupportsAnimatedTransition=false` → 自动降级同步提交 | 0 处（拔插） |

**不需要动的**：`MapMutationService` 事务协议、`IMapRenderBackend` 接口、调用方（ArenaEventManager 之外的任何新事件玩法）、`IMapInteractionGate`、`TemporaryVisibilityService`、事件协议。

## 六、限制与陷阱（使用前必读）

1. **错峰模式**：仅 `Simultaneous` / `CenterToOuter` 有实现，其余枚举会 `LogWarning` 降级为 Simultaneous。
2. **锁粒度**：`MapInteractionGate.IsLocked(cell, type)` 忽略 `type`——所有交互类型共用一个锁集合；`LockCells`/`UnlockCells` 是格级。
3. **分帧提交**：`CommitSliced` 与动画互斥（强制 Duration=0）；期间禁止新事务；`HasSlicedCommitPending` 可查询。
4. **`EjectUnitsFromImpassableCells`**：纯位置迁移，不触发 `TryCaptureEnemyCell`、不写归属（决策 B）；找不到落点会释放占用并 `LogWarning`。
5. **预留区初始化绕过事务**：`ArenaEventManager.OnMapInitialized`（:98-99）直接写 `IsUnexplorable=true`（此时地图未渲染，属初始化阶段，非运行时变化）。
6. **宝箱摧毁恢复**：中心格 `movementCost=1f` 在事务外手动恢复（ArenaEventManager.cs:390）；Destroyed 提交只含 IsUnexplorable + 外环 movementCost——**高度不回落的决策仍生效，零 mesh 重建**。
7. **`Duration>0` 但后端不支持动画**：仅 LogWarning 并降级同步，不会报错——测试时注意区分。
8. **动画期间新几何提交**：自动强制完成相交旧动画（`ForceCompleteConflicting`，会发 `Cancelled` 阶段事件）；不相交的并行。
9. **TerrainGhost/FadeGhost**：为独占克隆 mesh + 共享材质，Finalize/失败路径会显式 `Destroy`（防泄漏），但对局中途异常中断动画需经 `Shutdown()` 兜底。
10. **迷雾遮罩**：`RebuildFogMask` 全量重建整图贴图（每 20fps 限频），性能预算内；瞬间点亮用 `ForceRefreshFogVisuals(snapCells)`，其余走渐变。
11. **归属 Patch**：未注入 `ILogisticsService` 时 `Apply(Owner)` 仍抛 `NotSupportedException`；注入后走 `SetOwner/ClearOwner`（含后勤重算+事件）。
12. **嵌套事务/事务外 Apply**：抛 `InvalidOperationException`；`Rollback()` 只清补丁+解锁（幂等）。
