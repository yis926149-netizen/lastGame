# 三态记忆迷雾实施方案

## 目标

在已完成的"迷雾集成地形 Shader"（未探索地块渲染为迷雾、参与深度、无接缝）基础上，把战争迷雾从**两态**（未探索/已探索）升级为**三态记忆迷雾**：

- **未探索**：从未见过，全隐藏（迷雾）。
- **记忆区**：探索过但当前无己方视野——显示地形但**压暗**、只记得静态地物、**隐藏敌方动态单位**。
- **可见**：当前有己方视野——全部正常显示，包括敌方单位实时位置。

同时补齐一个长期缺失的问题：**未探索地块上的物体（地貌、资源、敌方单位/建筑/势力范围）没有被隐藏**。本方案用一套集中式、事件驱动、按归属分规则的机制统一处理。

---

## 已确认的前置决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 迷雾语义 | **三态 / 记忆迷雾** | 未探索 → 记忆区（探索过·无视野）→ 可见 |
| 己方可见性 | **己方永远可见** | 己方单位/建筑/城市/势力范围不受迷雾影响 |
| 隐藏动态物体方式 | **只关渲染，保留逻辑** | 敌方单位用 `Renderer.enabled=false`，不 `SetActive(false)`，避免冻结 AI/回合逻辑 |
| 当前视野来源 | **固定半径（先做）** | 己方单位按 `ViewPoints` 圈、城市按常量圈，六边形 BFS 点亮 |
| 记忆区敌方处理 | **简化：无快照** | 敌方建筑/城市按当前真实状态显示，敌方单位隐藏，不存历史快照 |

## 现有架构（复用，不重造）

探索的数据与事件流已经很规整，本方案完全建立在其上：

```
行为(移动/部署/建造/AI/回合/开局)
  → 若干 cell.ExploreThisHexCell()            // 单一数据源：HexCellData.IsExplored（单向 false→true）
  → _mapVisualEvent.Raise()                   // 单一事件：OnMapVisualChanged
      → MapRenderer.UpdateExplorationVisuals() // 刷地形/水/河流顶点色（已接入迷雾）
      → SphereOfInfluenceRenderer.RefreshAllSpheres()  // 重建势力范围
```

**问题诊断**：可见性没有统一应用点。`ExploreThisHexCell` 里只有零散的"显示"分支（`SetActive(true)`）、没有"隐藏"；地貌/资源完全没接入；势力范围走另一条重建路径也没接探索过滤。

## 三态语义（归属 × 状态 完整规则表）

| 物体 | 未探索 | 记忆区（探索过·无视野） | 可见（有视野） |
|---|---|---|---|
| 地形（核心/过渡/水/河） | 迷雾 | 正常但**压暗** | 正常全亮 |
| 中立地物（landform / resource） | 隐藏 | 显示（可压暗） | 显示 |
| 己方 单位/建筑/城市/势力范围 | —（不会在未探索区） | **始终显示** | 显示 |
| 敌方 **建筑/城市**（静态） | 隐藏 | 显示（无快照，当前真实状态） | 显示 |
| 敌方 **单位**（动态） | 隐藏 | **隐藏**（不知现在在哪） | 显示 |
| 敌方 势力范围 | 隐藏 | 隐藏（记忆区不显敌方势力范围） | 显示 |

> 记忆迷雾的灵魂：**记得敌城的位置，但看不到敌军的动向**。

## 数据模型

从 1 个 bool 扩到 2 个状态位：

```csharp
public bool IsExplored { get; private set; }  // 已有。单向 false→true，永久。"这辈子见过没"
public bool IsVisible;                          // 新增。每回合/每次行动重算，反复 true↔false。"现在能不能看到"
```

- 状态判定：`!IsExplored` = 未探索；`IsExplored && !IsVisible` = 记忆区；`IsVisible` = 可见。
- **顶点色通道**：`.r` = IsExplored、`.g` = IsVisible（迷雾方案文档里 `.g` 本就是预留给"当前可见"，此处正式启用）。

## 核心新增：视野计算 FieldOfViewService

三态相对两态多出来的大头，全新逻辑：

```
Recompute()（回合开始 / 己方单位移动、生成、消亡 / 建城 后）：
  1. 所有 cell.IsVisible = false                  // 先全部熄灭
  2. 对每个己方单位、城市：
       把其视野范围内的格子 IsVisible = true       // 六边形 BFS N 圈
       同时若 !IsExplored 则 ExploreThisHexCell()   // 第一次看到 = 永久探索
  3.（由现有 Raise() 触发）顶点色刷新 + 物体可见性同步 + 势力范围重建
```

**关键接线**：重算视野必须排在刷新**之前**。做法是让 `FieldOfViewService.Recompute` 成为 `OnMapVisualChanged` 的**第一个监听者**（或在 `Raise()` 前显式调一次），保证"先算 IsVisible，再画"。

**视野半径**：单位用 `UnitData.ViewPoints`；城市无对应字段，给常量（建议 2 圈）或复用"城市势力范围内全可见"。

## 实施蓝图（4 阶段，每阶段 git 提交、可回滚）

### 阶段 1 · 地基（只看地形，验证 FoV）

- `HexCellData`：新增 `IsVisible` 字段。
- 新增 `FieldOfViewService.Recompute()`：全格熄灭 → 遍历己方单位（`ViewPoints` 圈 BFS）+ 城市（常量圈）点亮 `IsVisible`，首见即 `ExploreThisHexCell()`。
- 接线：`FieldOfViewService.Recompute` 在 `OnMapVisualChanged` 里**最先**执行。
- Shader：`FogBlend.cginc` 顶点色启用 `.g`，已探索部分做 `lerp(记忆压暗系数, 1.0, g)` 亮度调制；迷雾部分不受影响。`MapRenderer.UpdateExplorationVisuals` 顶点色写入 `.g = IsVisible`。三个地形 Shader + 水 + 河流自动生效（逻辑集中在 include）。
- **验证**：走到哪亮到哪、离开变暗（记忆区）、没去过是迷雾。

### 阶段 2 · 物体可见性（集中式）

- 新增 `SyncCellObjectVisibility()` 挂 `OnMapVisualChanged`，按"归属 × 三态"表遍历设置：
  - 中立地物（landform / resource）：`SetActive` 按所在格 `IsExplored`。
  - 敌方单位：`Renderer.enabled` 按 `IsVisible`（只关渲染保逻辑）。
  - 敌方建筑/城市：按所在格显隐（记忆区显示、未探索隐藏）。
  - 己方：跳过（永远可见）。
- 删掉 `ExploreThisHexCell` 里零散的 `SetActive(true)`，收敛到这一处。

### 阶段 3 · 敌方势力范围过滤

- `SphereOfInfluenceRenderer.RefreshAllSpheres`：敌方 cells 生成 mesh 前按 `IsVisible` 过滤（己方不过滤）。

### 阶段 4 · 无快照收尾

- 记忆区敌方建筑/城市按当前真实状态显示、敌方单位隐藏——已由阶段 2 规则表体现，无需额外快照系统。

## 设计原则（为什么这么做）

- **单一数据源**：`IsExplored`（永久） + `IsVisible`（每回合）两个状态位，别处只读不写副本。
- **单一驱动事件**：一切显隐都由 `OnMapVisualChanged` 驱动，顺序固定为"先算视野 → 再刷视觉"。
- **单一应用点**：物体可见性集中在 `SyncCellObjectVisibility` 一处，杜绝碎片化的 `SetActive`。
- **按归属分规则**：中立按格、己方恒显、敌方按视野——三条清晰规则覆盖所有物体。
- **动态物体只关渲染**：敌方单位 `Renderer.enabled=false`，保留其移动/AI/回合逻辑，避免迷雾里的敌人冻结或回合逻辑出错。
- **性能**：地图数百格、事件不高频（玩家操作 / AI 回合才 Raise），全量遍历 O(n) 足够；如需优化再引入"新探索/新可见格子脏列表"做增量。
