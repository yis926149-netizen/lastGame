# 地图迷雾边界曲线/锯齿化 —— 实现文档（最终版）

> 目标：把原本"贴着六边形棱的硬边"探索边界，改成不规则的、大致贴合原边界的**曲线**（可选像素阶梯块）。并把同一套机制复用到**"记忆区↔可见区"**的分界线上。要求：大致贴合原线、不过多侵占已探索/暴露未探索、**不新增任何对地块内容的遮挡**。

---

## 一、背景：原来的边界是怎么来的

**原边界没有任何"描边几何"，是地形 shader 里逐顶点三态迷雾的副产物。**

- 每个地块顶点带颜色：`.r = IsExplored(0/1)`、`.g = IsVisible(0/1)`（`MapRenderer.FogVertexColor`）。
- 地形 shader（`TerrainBase_Fog` 等 + `FogBlend.cginc`）把 `.r/.g` 在三角形内插值，`FogBlend_final` 据此决定：未探索→覆盖为迷雾自发光；记忆区(已探索·无视野)→整体压暗到 `_FogMemoryDim`(0.45)+染色；可见→正常。
- 因为顶点色近乎硬跳变，**两条分界线都死死贴着六边形棱**，没有任何曲线/锯齿。

> 关键认知：**逐顶点插值的场无法在"被噪声偏移后的位置"采样**，所以想让边界起伏，必须把状态做成一张**可采样的世界对齐遮罩纹理**。这决定了整体走"方案 B"。

---

## 二、走过的弯路（为什么是现在这套）

按时间顺序，每一步都是被上一步的失败逼出来的，值得留档：

1. **方案 A（纯 shader，改顶点色边缘）** —— 想直接在 `FogBlend.cginc` 里对插值 `exploration` 做"量化+噪声阈值"。
   - ❌ 失败 1：阈值 `0.5+(n-0.5)*amt` 越界 (0,1) → 把**纯迷雾/纯地形的大片内部**也随机翻面 → **满屏黑块**。（教训见 playbook）
   - ❌ 失败 2：即使 `clamp` 修掉黑块，顶点色是**硬跳变、无渐变带可推** → 边界**完全没有锯齿**。
   - ⇒ 结论：方案 A 先天做不出，必须有一张"可采样的渐变场"。

2. **方案 B（世界探索遮罩贴图）** —— 自建一张世界对齐遮罩，shader 采样它。
   - ❌ 失败 3：用**白噪声**逐像素格独立扰动阈值 → 出来是**分散的椒盐方块**，不是连贯边界。（教训见 playbook）
   - ✅ 修正：改用**低频相干噪声做"边界域扭曲"** + 按格量化 → 连贯的阶梯/曲线。

3. **像素块 → 曲线** —— "方块感"完全来自"量化到像素格"。去掉量化（连续采样 + `fwidth` 抗锯齿）即得**平滑曲线**。保留为一个开关。

4. **更碎 / 更贴边** —— 调波长/幅度/遮罩精度；并把盖章从**外接圆**（外扩 0.4、扇贝感）改为**精确正六边形**（完美平铺、贴棱）。

5. **复用到"记忆区↔可见区"边** —— 遮罩升级双通道 `R=explored / G=visible`，同一套 warp 跑两遍。

---

## 三、最终实现

### 3.1 数据侧：世界对齐双通道遮罩 `_FogMaskTex`

`MapRenderer.cs`：

- **纹理**：`RGBA32`、`linear`、`Bilinear`、`Clamp`，尺寸 = 地图世界包围盒 / `fogMaskTexelSize`（上限 1024²）。用与 `_FogMapOrigin/_FogMapSize` **完全相同**的世界映射，保证和 shader 采样对齐。
- **R 通道 = IsExplored**：单调只增 → **增量盖章**，新探索格盖一次（`_fogMaskStamped` 去重）。
- **G 通道 = IsVisible**：逐回合动态 → **每次先整体清 G，再盖当前所有可见格**（"可见→记忆"的回退被"清空"天然覆盖）。
- **盖章形状 = 精确正六边形**（尖顶朝 ±z、平边在 ±x，内切半径 = `InnerRadius`）：点在六边形内 ⇔ 在三条边法向(0°/60°/120°)上的投影都 ≤ 内切半径。六边形完美平铺 → 无缝、无外扩、贴棱。
- **挂载点**：`UpdateFogMask()`，在 `OnMapVisualChanged` 里 `_fieldOfView.Recompute()` 之后调用。每次整图 `SetPixels32 + Apply`（纹理小，成本可忽略）。

### 3.2 Shader 侧：`FogBlend.cginc`

曲线机制拆成两个可复用助手，explored/visible **共用同一次 warp**：

```hlsl
// 像素量化(可选) + 低频相干噪声域扭曲 → 采样用 UV
float2 FogBlend_warpUV(float2 uv) {
    worldXZ = uv*size+origin;
    samplePos = (_FogPixelSize>0) ? 量化到格中心 : worldXZ;   // 像素块 or 曲线
    off = (valueNoise(samplePos*freq) - 0.5) * 2 * _FogJaggedAmount;  // 低频相干，连贯起伏
    return (samplePos + off - origin)/size;
}
// 通道值二值化：像素→硬 step；曲线→fwidth 抗锯齿 smoothstep
float FogBlend_resolveEdge(float v) { ... }
```

- `FogBlend_surf`：`exploredJagged = resolveEdge(采样.r)` → 决定地形/迷雾（未探索仍覆盖为迷雾）。
- `FogBlend_final`：**一次采 `.rg`**，`exploredJagged=resolveEdge(rg.r)`、`visibilityJagged=resolveEdge(rg.g)`；把压暗用的裸 `visibility` 换成 `visibilityJagged`：
  ```hlsl
  lit        = color.rgb * lerp(_FogMemoryDim, 1.0, visibilityJagged); // 压暗从曲线边开始
  memoryZone = exploredJagged * (1.0 - visibilityJagged);
  color.rgb  = lerp(fogEmission, lit, exploredJagged);
  ```
- **无签名改动**：三个含 `FogBlend.cginc` 的 shader（`TerrainBase_Fog` / `ThreeMaterialBlend_Land` / `RealMaterialMaskBlend`）早已把 `fogCoord` 传进 `FogBlend_final`，`final` 内部自取 uv 采 G，调用点一个都不用改。

### 3.3 为什么满足"不新增遮挡"

- 记忆区处理是**压暗**（内容一直显示），不是覆盖 → 换成曲线边后仍只压暗，零新增遮挡。
- 地块上的建筑/单位/资源是**独立 GameObject**，由 `SyncCellObjectVisibility` **按格**显隐，**这套 shader 碰不到它们**；且**刻意不把物体接到这张 jagged 遮罩**，避免物体沿锯齿闪进闪出。
- `G ⊆ R`（可见必已探索）+ 共用同一 warp → 可见曲线边恒在探索曲线边**内侧**，不穿帮，两条边同风格。

## 四、参数（`MapGenerationConfigSO` → “迷雾锯齿边界”）

| 参数 | 默认 | 作用 | 调法 |
|---|---|---|---|
| `fogPixelSize` | `0` | **0=平滑曲线**；>0=像素阶梯块（值=方块世界边长） | 想要像素块就设 >0，越小越细 |
| `fogJaggedAmount` | `1.0` | 边界起伏**幅度**（世界单位），在原线两侧摆动多远 | 越小越贴边；0=贴合遮罩形状 |
| `fogNoiseWavelength` | `2.0` | 边界起伏**波长**（世界单位），凸起/凹口大小 | **越小越碎**（密集小弯） |
| `fogMaskTexelSize` | `0.8` | 遮罩每 texel 世界尺寸 | 越小越**贴合六边形棱**、越大越圆润 |

> 探索边与可见/记忆边**共用全部参数**，风格自动一致，无额外参数。

## 六、已知取舍与后续

- **G 每回合全量重建 + 上传**：与现有"每回合重刷顶点色"同量级，通常可忽略。若 `OnMapVisualChanged` 触发过密影响性能，可加"可见集哈希变了才重建 G"的脏检查。
- **盖章用规则六边形**（未含逐格顶点扰动）：与实际渲染的微扰六边形略有偏差，可忽略；如需完全贴合可改用 `SolidAreaVertices` 的实际角点做多边形判定。
- **单层噪声**：波长调很小后可能"碎得单调"。如需大小不一的层次感，可给 `valueNoise` 叠加第二个高频倍频（fBm）。
- **像素块模式**（`fogPixelSize>0`）与曲线模式共存，随时切换。

## 附：相关调试经验（已入 `.claude/debugging-playbook.md`）

1. 噪声阈值二值化做边缘：阈值必须钳在场值两端内，否则翻的是整片内部（黑块/空洞）。
2. 程序化锯齿：**白噪声出椒盐方块，连贯边要用低频相干噪声做域扭曲**再阈值。
