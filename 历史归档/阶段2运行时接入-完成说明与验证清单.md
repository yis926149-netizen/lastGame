# 阶段2 运行时接入 —— 完成说明与验证清单

> 本文件记录「阶段2 运行时接入」的改动内容、数据对齐关系，以及必须在 Unity 中完成的验证步骤。

| unit.angry_mushroom | 1 | 兵营默认产出 |
| unit.cactus / free_lich / green_skin / ranged_iii / melee_iii | 2/3/4/5/6 | |

## 三、Unity 验证步骤（需在 Unity 中执行）

1. **导入运行库**：Unity 菜单 `Tools → 游戏配置 → 导入并校验`，确认 Console 输出「生成 14 个单位、7 个建筑、4 张普通卡，保底卡: building.arrow_tower」。
2. **拖引用**：打开场景中的 `GameInstaller`，把 `Assets/GameConfig/Generated/` 下的三个 asset 拖到新增的三个字段：
   - `_unitBalanceSO` ← `UnitBalanceDatabase.asset`
   - `_buildingBalanceSO` ← `BuildingBalanceDatabase.asset`
   - `_cardPoolDatabaseSO` ← `NormalCardPoolDatabase.asset`
3. **编译**：确认 Console 无编译错误（若有 asmdef/GUID 报错，见「五、风险」）。
4. **进入 Play 验证数值源切换**：
   - 单位生成：任意非移民单位 HP=20、攻击=15、攻击间隔=1.5（此前 attackInterval 有 0 的 bug，现应统一为 1.5，settler 为 0）。
   - 抽卡/卡池：手牌与预告卡只从 {archer, barracks, arrow_tower, swordsman} 出；**第一张保底是 arrow_tower**。
   - 玩家扣费：出 archer 扣 50、swordsman 扣 40、barracks 扣 120、arrow_tower 扣 100（金币栏可观察）。
   - AI 扣费：观察 AI 出牌，同样按上述卡费扣减（可断点 `AICardBrain.TryPlaySingleCard`）。
   - 建筑：任一建筑 HP=100；金矿地块每结算周期 +1.5 金币（配合天赋乘数）。
5. **双轨回退验证**：把三个数值 SO 字段置空（或临时删除三个 asset），重新 Play，游戏应仍按 Legacy SO 数值运行（行为与迁移前一致）。
