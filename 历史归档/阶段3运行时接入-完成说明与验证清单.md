## 一、本次完成的改动

### 1. Excel/Schema 新增三张表

| 工作表 | 主键 | 内容 |
|---|---|---|
| `战术卡` | `cardId` | 效果类型、治疗比例、攻/速乘数、持续时间、初始数量 |
| `天赋卡` | `talentId` | 效果类型、目标属性、数值、权重、可否重复 |
| `天赋抽卡规则` | `ruleId` | triggerTalentId → targetCardType → weightMultiplier |

真实迁移数据（`Config/Excel/游戏数值配置.xlsx` 已重新 init，`Config/Generated/` 已重新导出）：

- 战术卡：`tactical.repair`（enabled=true，healRatio=0.3）；`tactical.battle_order`（enabled=false，attackMultiplier=1.3 / speedMultiplier=1.3 / duration=5）。
- 天赋卡：`talent.damage`（×2 damage）、`talent.building_hp`（×4 buildingHp）、`talent.gold`（×2 gold）。
- 抽卡规则：`talent.damage → Unit ×10`；`talent.building_hp → Building ×10`（与原硬编码语义一致，但改为显式配置）。

### 2. 资源 SO 的 ID 迁移为稳定字符串 ID

5 个 asset 的 `cardId`/`talentId` 由数字字符串迁移为稳定 ID（`tactical.repair` / `tactical.battle_order` / `talent.damage` / `talent.building_hp` / `talent.gold`）。数值字段（effectType/effect 等）作为 Legacy 兜底保留，资源字段（图标）不变。

### 3. 数值运行库（Excel 生成，只读）

新增 `TacticalCardBalanceData/DB`、`TalentCardBalanceData/DB`、`TalentDrawRuleData/DB`；`GameConfigImporter.ImportAll` 一次生成 6 个 SO（单位/建筑/普通卡池/战术卡/天赋卡/抽卡规则）。

### 4. Provider 改造

| 文件 | 说明 |
|---|---|
| `TacticalCard/TacticalCardPresenter.cs` | 启用卡列表由 Excel `EnabledCards` 驱动，按 `cardId` 找资源；effectType/effect 数值从 Excel 读 |
| `TalentCard/TalentCardProvider.cs`（新） | 天赋启用卡列表 + `DrawRandom` 抽卡 + `GetBalance` 查 Excel 数值 |
| `TalentCard/TalentCardTriggerAdapter.cs` | 改用 `TalentCardProvider`（替代 `TalentCardPoolSO`） |
| `TalentCard/TalentCardEffectApplier.cs` | 效果数值从 Excel（balance）读，缺失回退 Legacy |

### 5. 抽卡规则去串线

`CardGenerationRule` 删除硬编码 `talentId "0"/"1"`，改为查询 `TalentDrawRuleDatabaseSO.EnabledRules`（triggerTalentId → targetCardType → weightMultiplier）。`CardService`/`AICardBrain` 注入规则库并传入。

### 6. 描述格式化器

新增 `TalentCard/TalentDescriptionFormatter.cs`，由 `effectType/statId/value` 生成精确文案（如“攻击力 ×2”“建筑生命值 ×4”），接入 `TalentCardSelectionUI`（DescText 优先格式化文案，缺失回退 Legacy 人工文案）。

### 7. DI 绑定

`GameInstaller` 新增三个可选数值库字段（战术卡/天赋卡/抽卡规则），非空才绑定；新增 `TalentCardProvider` 绑定。

## 三、Unity 验证步骤（需在 Unity 中执行）

1. **导入运行库**：菜单 `Tools → 游戏配置 → 导入并校验`，确认输出「6 张表、3 张天赋卡、2 张战术卡、2 条抽卡规则」。
2. **拖引用**：把 `Assets/GameConfig/Generated/` 下三个新 asset 拖到 `GameInstaller` 新增字段：
   - `_tacticalCardBalanceSO` ← `TacticalCardBalanceDatabase.asset`
   - `_talentCardBalanceSO` ← `TalentCardBalanceDatabase.asset`
   - `_talentDrawRuleSO` ← `TalentDrawRuleDatabase.asset`
3. **编译**：确认无编译错误。
4. **验证战术卡**：
   - 进入 Play，战术卡栏应**只出现「维修」卡**（战斗号令因 enabled=false 不出现）。
   - 对残血建筑使用维修卡，回血 30% 最大 HP（`tactical.repair` healRatio=0.3）。
5. **验证天赋卡**：
   - 开局/占领公共建筑触发天赋三选一，描述应显示「攻击力 ×2」「建筑生命值 ×4」「金币获取 ×2」（格式化文案，而非模糊文案）。
   - 选「攻击力 ×2」后，玩家单位攻击结算 ×2（`CombatResolver` 走 `GetStatMultiplier("damage")`）。
6. **验证抽卡偏好去串线**：
   - 拥有「攻击力 ×2」天赋后抽普通卡，单位卡权重 ×10（可断点 `CardGenerationRule.GenerateNextCard` 观察 unitWeight/buildingWeight）。
   - 拥有「金币获取」天赋时**不产生任何偏好**（均匀随机）。

## 五、回滚方式
