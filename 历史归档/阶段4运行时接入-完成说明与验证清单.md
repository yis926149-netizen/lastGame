# 阶段 4 运行时接入-完成说明与验证清单

## 一、目标回顾

按 `Excel配置表混合架构修改计划.md` 阶段 4，把探索奖励、地图资源、地图地貌、公共建筑四类数值迁移到 Excel 作为唯一数值源，Unity 侧通过 Provider 在运行时优先读 Excel 生成的只读 SO，缺失时回退 Legacy 手工 SO（双轨迁移开关）。

## 二、数据流

```
Excel（唯一数值源，7 张新表）
  → ConfigExporter 导出 CSV/JSON
  → Unity 导入器（Tools/游戏配置/导入并校验）
  → 只读 SO（数值）+ 手工资源 SO（prefab/图标）
  → Provider 合并（稳定 ID / legacyId 对齐，Excel 优先，Legacy 回退）
  → 运行时消费点
```

## 四、验证清单

1. **导入器**：菜单 `Tools/游戏配置/导入并校验`，确认 7 组 SO 生成到 `Assets/GameConfig/Generated`（或 Resources 目录），Console 无错误。
2. **DI 关联**：打开 `GameInstaller`，确认 7 个数值 SO 字段已填入（或用 `Tools/游戏配置` 自动关联菜单）。
3. **运行游戏**：
   - 地图上资源（动物/植物/矿物/宝箱）正常散布，health_pack 不生成（enabled=false）；
   - 地貌（森林/石地/巨骨/农田）正常散布，金矿按簇生成（3 堆）；
   - 农田格单位回血、金矿格金币加成生效；
   - 探索奖励：金币/单位（仙人掌、三阶射手）/战术卡（维修）/建筑（金矿）按权重出现；
   - 探索费用按奖励类型扣费；
   - 公共建筑（堡垒）生成，captureHp/defenseHp/subHexDirections 取自 Excel。
4. **可复现性**：同一地图种子下多次重开，资源/地貌/簇/奖励/公共建筑位置一致（随机流通过 SeedService 锁定）。
5. **非空池回归**：确认无「意外空池」警告（导入器已按 enabled 过滤 + 空表报错）。
