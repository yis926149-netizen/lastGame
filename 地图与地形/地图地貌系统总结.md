# 地图地貌系统总结

说明：地图上的**地貌（`Enums.LandFormType`）**是挂在六边形地块上的地形属性，与资源互斥，主要影响战斗防御、移动（设计意图）、回血。以下每句均附代码出处。

## 1. 地貌类型定义

定义在 `Assets/Scripts/Utilities/Enums.cs:43-55`：

```csharp
public enum LandFormType
{
    Forest,    //森林 - 移动力 - 1
    Stone,     //石头 - 地形高度 + 1
    BigBones,  //大骨阵 - 防御力增加
    FromLand,  //农田 - 每回合自动回血
    None
}
```

即枚举值：`Forest=0, Stone=1, BigBones=2, FromLand=3, None=4`。注意 `Assets/Scripts/Data/HexBuildings.cs:13` 还有一个**重复的旧 `LandFormType` 枚举**，与 `HexLandForm.cs:10`（旧数据类）一样是回合制时代遗留，全项目无引用。

## 2. 生成

- **时机**：地图生成管线中，河流生成之后、资源生成之前（`MapGenerator.cs:126-128`）。
- **随机源**：独立的 `SeedService.GetRandom("LandForm")`（`MapGenerator.cs:105`），种子常量 301（`SeedService.cs:7,34`）。
- **条件**：跳过湖泊/海洋和有河流的格（`MapGenerator.cs:254`）；**与资源互斥**——有地貌的格不生成资源（`MapGenerator.cs:271-272`）。
- **概率**：`random.Next(0, 5+9=14)` 再 `Clamp` 到 0~4（`MapGenerator.cs:257`）。掷到 0~3 → 四种地貌各 1/14 ≈ 7.1%；4~13（10 份）→ `None` ≈ 71.4%。即**每合格格约 28.6% 概率出现地貌**。

## 3. 数据存储与模型

- 数据挂在地块上：`HexCellData.landFormType`（`HexCellData.cs:18`）与 `landFormModel`（`:19`），读取用 `GetLandForm()`（`:362-365`）。
- 移动消耗：`movementCost` 默认 1，水域格构造时设为 `float.MaxValue`（不可通行，`HexCellData.cs:27,311-313`）。
- 模型：`MapRenderer.InstantiateLandForms`（`MapRenderer.cs:1066-1085`）——`None(4)` 跳过（`:1074`），从 `EnvironmentModelsSO.landFormModels` **按枚举索引**取预制体（`:1075`、`EnvironmentModelsSO.cs:7`、`EnvironmentModelsProvider.cs:17`），实例化到 `RealCenterWorldCoordinate`，挂 `ModelController`，设 `FogAffectedEnvironment` 层参与选择性雾化（`:1077-1079`）。
- 雾化：`FogEnvironmentSelectiveEffect.Initialize(_landFormRoot, _resourceRoot)`（`MapRenderer.cs:1117-1119`），逐 Renderer 重绘对象遮罩（`:1626-1648`）。
- 显隐：地貌模型**全图始终可见**，不随探索隐藏；公共建筑区域也只隐藏资源模型、不动地貌（`PublicBuildingGenerator.cs:270-271`）。

## 4. 已实现的效果

### 4.1 农田（FromLand）—— 站格自动回血

- 实现于 `UnitBrainBase` 回血计时器：`TickLandHeal`（`UnitBrainBase.cs:76-91`）——单位当前格是 `FromLand` 时计时，每 5 秒回 **10% 最大 HP**（常量 `HealInterval=5f`、`LandHealRatio=0.1f`，`:33-34`），**离开农田立即重置计时器**（`:79-82`）。
- 驱动：`UnitBrainBase.Update`（`:56-68`），暂停时整体跳过（`:58`）。
- 注意：README 中"`GameLoop` 驱动回血计时器（农田/祭坛，每 5 秒）"与实现不符——`GameLoop.Tick` 只驱动公共建筑和全局计时器（`GameLoop.cs:74-77`），回血实际由单位自身的 `Update` 驱动。

### 4.2 大骨阵（BigBones）—— 防御 +0.3

- 战斗结算时按**被攻击者所在格**刷新：在骨阵格 `LandFormType_BigBones = 0.3f`，否则清零（`CombatResolver.cs:99-102`），再计入伤害公式 `DefenseGain`（`:132`）。
- 同一公式的镜像残留：旧 `UnitMovementController.AttackDataComputation` 也做同样的刷新与计算（`UnitMovementController.cs:367-370,393-395`），是实时化改造前的旧攻击结算路径。

### 4.3 河流（hasRiver）—— 防御 -0.5

- 属于河流地形而非地貌，但在同一防御公式中：被攻击者格有河则 `LandFormType_River = -0.5f`（`CombatResolver.cs:104-107,132`）。

### 4.4 地形高度差 —— 攻击 ±0.5

- 同属战斗地形要素：攻击方比被攻击方高 1 级以上 +0.5 攻，反之 -0.5（`CombatResolver.cs:117-122`），攻击雕像 +0.7/格（`:109-115`）。

## 6. 与资源（道具）系统的关系

- **生成互斥**：一格只能有地貌或资源其一（`MapGenerator.cs:271-272`），先掷地貌、后掷资源。
- **配置差异**：资源已完成 SO 配置化（`MapResourceSO`）；地貌仍为"枚举 + 硬编码 + 按索引取模型"，且 `LandFormConfigSO` 是孤悬的死配置。
