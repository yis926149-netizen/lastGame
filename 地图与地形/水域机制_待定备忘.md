# 水域机制 — 待定备忘

## 当前状态（2026-07-20 · 已重构海面体系）

- 水域判定集中到 `WaterLevelConfig.WaterLevel`，由 `MapGenerator` 从 `_config.seaLevel` 注入。
- 所有分散的 `Height <= 0` / `Height == 0` 已替换为 `WaterLevelConfig.IsWater()`。
- `IsWater` 同时支持传入 `float height` 或 `HexCellData cell`。

### 海面体系重构（关键）

**核心：彻底解耦「地形高度（整数分类）」与「世界Y坐标」。**

- `Height` 是整数级差单位（噪声 0~5），**只用于分类/判定**（水陆、坡vs台阶、河流走向、攻击加成）。
- 世界Y = `Height * elevationStep`（`elevationStep` 默认 **3**，配置在 `MapGenerationConfigSO`）。
  - 唯一换算点：`MeshDataGenerator.cs:43`（地表）。下游模型/单位/建筑/相机/寻路走 `RealCenterWorldCoordinate` 自动跟随。
- 竖直扰动 `HexMetrics.PerturbY2` 从 **±5 无界** 改成 **有界 ±(elevationStep × verticalPerturbRatio)**，默认 ratio=0.4 → ±1.2。
  - 强度由 `MapGenerator.cs:48` 注入 `HexMetrics.yPerturbStrength`。
  - ⚠️ 只改 `PerturbY2`（唯一调用点 `MeshDataGenerator.cs:102`）；台阶中间点是故意只做 XZ 扰动，勿动。
- 海面世界Y = `(seaLevel + waterSurfaceOffset) * elevationStep`（`MeshDataGenerator.cs` GetlakeOrSeaVertices）。
  - `waterSurfaceOffset` 默认 **2**（配置在 `MapGenerationConfigSO`）：视觉水面顶到判定水位之上第2层的名义高度。
  - **视觉水面与判定水位(seaLevel)有意解耦**：seaLevel 决定通行/材质/海岸判定；waterSurfaceOffset 只调画出来的海面平面高度。
  - 海岸边缘（CoastRect/CoastTri）已压平到水面高度：保留 XZ、Y 取水面Y，不再斜爬到陆地海岸线（水陆竖直落差不再由此填充，陆地朝海侧壁未封）。
- 海底**照常生成**（未做特殊固定平面）；不区分深浅海。
- `stepHeight` 保持 **1**（整数级差单位，世界Y缩放由 `CreateStepPoints` 的 yIncrement 自动吸收）。
