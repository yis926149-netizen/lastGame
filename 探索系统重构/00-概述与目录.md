# 探索系统重构 · 概述与目录

## 核心方向

原"三态记忆迷雾"方案已废弃。新方向是将两个此前混在一起的概念彻底拆开：

| 原混合概念 | 拆分后 |
|---|---|
| 迷雾 = 未探索区域的视觉遮挡 | 地图展示层：地形/单位/建筑始终完整显示 |
| 探索 = 单位视野/移动自动触发 | 探索层：玩家主动支付资源，永久解锁地块操作权 |

**`IsVisible` 和玩家视野 FoV 将被移除。**  
**`AIFogService` 一并删除，AI 与玩家行为一致：地图全可见，需探索才能操作未探索格。**

---

## 新的"探索"语义

探索不再表示"获得视觉情报"（因为地图始终完整可见），而是一个**复合动作**：

> 玩家花费资源探索一个地块，一次性完成：
> 1. 将地块标记为已探索
> 2. **占领该地块**（圈入玩家势力范围）
> 3. **收割该地块资源**（资源系统后续需重构）

未探索的地块可以看见，但不能在其上执行受限操作（部署、攻击目标等，详见 `01-本身逻辑.md`）。

> **重要规则：**
> - 玩家开局有**一个主城**（唯一），占 1 格，周围一环（6 格）为固有势力范围
> - 开局赠送 **1 次免费探索**（玩家选择势力范围相邻地块）
> - **不能建新城**（建新城功能移除）
> - **探索是势力范围拓展的主要方式**；另一来源：占领公共建筑（见 `06-公共建筑与探索系统对接.md`）
> - 单位/建筑只能部署在己方势力范围内

## 当前代码现状快照

| 组件 | 当前状态 | 重构后去向 |
|---|---|---|
| `HexCellData.IsExplored` | 有，被多处自动写入 | 保留，改为只由 `ExplorationService` 写 |
| `HexCellData.IsVisible` | 有，实际 = IsExplored | 删除 |
| `FieldOfViewService` | 有，但 `Recompute()` 只做 `IsVisible = IsExplored` | 删除玩家侧；BFS工具函数提取到通用工具 |
| `AIFogService` | 有，独立 AI 视野 | **删除**，AI 与玩家行为一致 |
| FogMask / FogBlend.cginc | 有，控制地形迷雾遮挡 | **改造**（去饱和+半透明雾），保留锯齿边界 |
| 水/河流 Shader 探索逻辑 | 有，按探索状态压暗/隐藏 | **改造**（去饱和+半透明雾），删除压暗和 Alpha 消除 |
| `MapRenderer.SyncCellObjectVisibility` | 有，按探索隐藏地貌/资源/建筑/单位 | 删除 |
| `SphereOfInfluenceRenderer` IsVisible 过滤 | 有 | 删除过滤 |
| `AIEntityFactory` SetActive(false) | 有，新生成AI实体被隐藏 | 删除 |
| 自动探索（移动/部署/建城） | 多处 | 全部删除 |
| 建城系统（UIController/PlayerUnitBrain） | 有 | **移除建新城功能**，保留主城（唯一） |
| 势力范围来源 | 城市圈地 | 主城固有范围 + 探索地块占领 |
| 建筑拓展势力范围 | 可能存在 | 普通建筑**禁止**；公共建筑占领后自动扩张（强制覆盖）；公共建筑及其周围一环**不可通过探索获取** |
| 资源收割（探索时） | 独立操作 | **探索时自动收割**（资源系统后续重构） |
| 主动探索服务 | 不存在 | 新建 |
| 探索资源钱包 | 不存在 | 接口占位，后续接入 |
| 探索视觉标记层 | 不存在 | 不再需要（方案三由 Shader 处理，费用标签用 Canvas） |
