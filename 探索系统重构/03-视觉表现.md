# 探索系统重构 · 03 视觉表现

## 核心原则

> 探索状态不允许**遮挡或隐藏**任何地形、水域、河流、地貌、资源、单位、建筑或势力范围。
> 
> 方案三采用**地形去饱和 + 半透明迷雾叠加**，让未探索区有雾气质感但不丢失地形信息。
> 
> 单位/建筑使用独立材质，不受地面 Shader 影响，在未探索区中始终完整可见。

### 方案三架构

```
已探索格：地形正常渲染（不改任何东西）
未探索格：
  1. 地形材质的最终颜色 → 去饱和到 50%（保留明暗和轮廓，颜色褪成灰蓝调）
  2. 叠加半透明迷雾色（复用现有 _FogTex 噪声 + _FogColor，混合强度 ~50%）
  3. 结果：地形清晰但明显"蒙了一层冷色薄雾 + 褪色"
```

## 1. 需要清理的现有视觉逻辑

### 1.1 地形 Shader（改造而非删除）

三个地形 Shader 需要**改造** `FogBlend_surf` 和 `FogBlend_final`，从"硬切两态"改为"去饱和+半透明雾"。

| Shader 文件 | 操作 |
|---|---|
| `TerrainBase_Fog.shader` | 不改 include，只改 FogBlend 函数行为 |
| `RealMaterialMaskBlend.shader` | 同上 |
| `ThreeMaterialBlend_Land.shader` | 同上 |

**当前逻辑（两态硬切）**：
- `FogBlend_surf`：未探索 `exploredJagged=0` → 地形 Albedo 乘 0 = 全黑，用纯迷雾自发光替换
- `FogBlend_final`：`lerp(迷雾色, 正常光, exploredJagged)` → 未探索完全被迷雾覆盖

**改造后逻辑（去饱和+半透明雾）**：
- `FogBlend_surf`：未探索 `exploredJagged=0` → 地形 Albedo **不再乘 0**，正常采样地形贴图和光照
- `FogBlend_final`：未探索 `exploredJagged=0` → 地形色去饱和 + 半透明雾叠加，而非完全替换

### 1.2 水面 Shader

`LakeorSea.shader:150-159`：当前未探索用纯迷雾覆盖、已探索但无视野压暗。

**改造**：与地形一致，未探索时水面颜色去饱和 + 叠加半透明雾。删除压暗逻辑（`_FogMemoryDim`），因为不再有"记忆区"概念。

### 1.3 河流 Shader

`River.shader:79-85`：当前未探索 `o.Alpha *= explored` 让河流直接消失。

**改造**：删掉 Alpha 消除，未探索区河流正常显示。同样施加去饱和+薄雾处理，与地形一致。

### 1.4 FogBlend.cginc（核心改造文件）

**保留**整套 include 架构，只改 `FogBlend_surf` 和 `FogBlend_final` 两个函数。

**删除**：
- `FogBlend_shadowClip`：不再需要（之前未探索格不投射阴影，现在正常投射）
- `_FogMemoryDim` / `_FogMemoryColor`：记忆区概念已移除

**新增 Shader 参数**：
```hlsl
float _FogUnexploredDesaturate;  // 未探索区去饱和强度 [0,1]，建议 0.5
float _FogUnexploredBlend;       // 迷雾色叠加强度 [0,1]，建议 0.4~0.6
float2 _FogScrollSpeed;          // 雾纹理滚动速度 (x,y) 世界单位/秒，建议 (0.02, 0.01)
```

**改造 `FogBlend_final`** （核心修改）：

```hlsl
void FogBlend_final(float exploration, float visibility, half3 fogEmission, inout fixed4 color, float2 uv_FogTex)
{
    float2 uvW = FogBlend_warpUV(uv_FogTex);
    float r = tex2Dlod(_FogMaskTex, float4(uvW, 0, 0)).r;
    float exploredJagged = FogBlend_resolveEdge(r);
    
    // 未探索区处理：
    // 1. 去饱和：将正常光照颜色转为灰度 + 冷色调
    // 2. 叠加半透明迷雾（保留 _FogTex 噪声质感 + _FogColor 色调）
    fixed3 unexploredColor = color.rgb;
    // 去饱和
    float gray = dot(unexploredColor, fixed3(0.299, 0.587, 0.114));
    unexploredColor = lerp(unexploredColor, gray * fixed3(0.85, 0.90, 1.0),
                           _FogUnexploredDesaturate);
    // 叠加半透明雾（UV 随时间缓慢滚动，雾纹漂移）
    float2 scrollUV = uvW + _Time.y * _FogScrollSpeed;
    fixed3 fogTex = tex2Dlod(_FogTex, float4(scrollUV, 0, 0)).rgb;
    fixed3 fogLayer = _FogColor.rgb * lerp(fixed3(1,1,1), fogTex, _FogTexAmount) * _FogEmission;
    unexploredColor = lerp(unexploredColor, fogLayer, _FogUnexploredBlend);
    
    color.rgb = lerp(unexploredColor, color.rgb, exploredJagged);
}
```

**改造 `FogBlend_surf`**：地形 Albedo 不再乘 `exploredJagged`——

```hlsl
fixed3 FogBlend_surf(float2 uv_FogTex, float exploration, fixed3 terrainAlbedo, inout fixed3 o_Emission)
{
    // 删除：terrainAlbedo *= exploredJagged（不再让未探索地形变黑）
    // 删除：o_Emission = lerp(fog, emission, exploredJagged)
    // 改为：正常返回 terrainAlbedo，让光照完整计算
    // 去饱和+雾叠加全部交给 FogBlend_final 统一处理
    return terrainAlbedo;
}
```

### 1.5 FogMask 纹理（保留+ 改造用途）

`MapRenderer.cs:1291-1445`：当前每帧将探索状态写入 `_FogMaskTex`（R 通道=已探索）。

**保留**这套上传逻辑，只需改动写入逻辑：
- 旧：R = `IsExplored`（需要 `FieldOfViewService.Recompute` 配合设置 `IsVisible`）
- 新：R = `IsExplored`（只需 MapRenderer 直接读取 `cell.IsExplored`，不再需要 FoV 服务）

G 通道（`IsVisible`）不再写入（不再有视野概念），可以保留但 Shader 不采样。

### 1.6 顶点色用途变更

`MapRenderer.cs:1332-1339`：

- R 通道：保留写入 `IsExplored`（作为局部探索状态源，供没有 FogMask 采样的场景使用）
- G 通道：不再写入 `IsVisible`，填 1.0 或删除
- 清理后顶点色 R 仍承载探索状态，但 Shader 中不用于遮挡，仅用于可选的边缘柔和过渡

## 3. FogCover（地图边缘装饰）

`FogCover.shader` + `FogManager.cs`：生成地图外边缘的迷雾封皮，覆盖地图外部区域。

这套逻辑**不是格内探索遮挡**，是地图边界外的背景装饰。

**建议：**
- 保留 FogCover 的几何体和 Shader，但与探索系统解耦。
- 考虑重命名为 `MapBorderCover`，避免与探索迷雾混淆。
- 不做强制要求，待确认产品是否保留地图边缘装饰效果。

## 4. Shader 改造方案三总览

### 复用清单

| 现有资产 | 用途 | 改动 |
|---|---|---|
| `FogBlend.cginc` | 迷雾逻辑 include | 改 `FogBlend_surf` + `FogBlend_final`，删除 `FogBlend_shadowClip` |
| `_FogTex` 迷雾噪声贴图 | 雾气质感纹理 | 不变 |
| `_FogColor` / `_FogEmission` | 雾颜色 / 发光强度 | 不变（参数数值可能需要调） |
| `_FogTexAmount` | 噪声叠加强度 | 不变 |
| `FogBlend_warpUV` + 锯齿边界 | 不规则起伏边界 | **完全不变**（这是"迷雾感"的关键来源） |
| `_FogMaskTex` 世界对齐遮罩 | 探索状态数据源 | 保留上传，只改 R 通道写入（去掉 FoV 依赖） |
| `_FogMapOrigin` / `_FogMapSize` | UV 映射 | 不变 |
| `TerrainBase_Fog.shader` 等三个 Shader | 地形渲染入口 | 不改 include，函数行为由 FogBlend 内决定 |
| `LakeorSea.shader` | 水面 | 改造去饱和+薄雾逻辑 |
| `River.shader` | 河流 | 删除 Alpha 消除，改造去饱和+薄雾逻辑 |
| MapRenderer FogMask 上传 | CPU 侧数据推送 | 保留，不再依赖 FoV 服务 |
| MapRenderer 顶点色写入 | 局部探索状态 | 保留 R 通道 |

### 不用的资产

| 资产 | 处理 |
|---|---|
| `FogBlend_shadowClip` | 删除（之后未探索格正常投射阴影） |
| `FogBlend_alpha` | 删除（Smoothness/Metallic 不再乘探索状态） |
| `_FogMemoryDim` / `_FogMemoryColor` | 删除（记忆区概念已移除） |
| `FogBlend_jaggedExploration` | 保留但简化（不再需要二值化，FogBlend_final 直接用平滑值做 lerp） |
| G 通道（IsVisible） | FogMask 和顶点色中停止写入 |

### 新增参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `_FogUnexploredDesaturate` | 0.5 | 未探索区去饱和强度 |
| `_FogUnexploredBlend` | 0.5 | 迷雾色叠加强度 |
| `_FogScrollSpeed` | (0.02, 0.01) | 雾纹理 UV 滚动速度（世界单位/秒），零额外开销 |

两个参数在 Material 面板暴露为滑块，方便实时调优。

### 边界锯齿效果

现有 `FogBlend_warpUV` 让探索/未探索边界呈不规则起伏曲线（通过低频噪声偏移 UV 采样位置）。**完整保留**，这是"更迷雾一点"的核心——它不是生硬的六边形格边，而是像真实雾边缘那样柔和蔓延。

### 费用标签（独立层，不受 Shader 影响）

未探索格的探索费用仍通过 World Space Canvas + TextMeshPro 标签展示。置于格子上方，不受地形 Shader 处理影响。费用数据来自 `IExplorationCostProvider.GetCost()`。

### 交互流程（探索模式）

```
常驻状态（任何时候）：
  未探索格：去饱和 + 半透明雾（Shader 自动处理）
  已探索格：正常颜色（Shader 自动处理）

探索模式按钮 → 进入探索模式：
  可探索格（邻接已占领格）→ 费用标签显示为可购买色（金/青色）
  不可探索格 → 费用标签灰色
  资源不足 → 费用标签红色

悬停可探索格：
  费用标签放大

点击：
  → IExplorationService.TryExplore(cell)
  成功 → 该格在下一帧切为正常色（FogMask R=1，Shader 自动过渡）
  失败 → 费用标签变红 + 提示文字
```

### Tile Click 选择探索目标

`PlayerInputHandler.CheckTileClickForExploration()`：

```
探索模式开启时，每次鼠标左键点击：
  1. 使用现有 Map Layer 射线（PlayerInputHandler.cs:85）
  2. 命中点通过 _mapDataService.GetCellByWorldPosition 获取 HexCellData
  3. 调用 _explorationService.TryExplore(targetCell)
  4. 成功：CellExplored 事件 → 地图渲染刷新，该格颜色过渡
  5. 失败：根据 ExploreResult 枚举返回状态（AlreadyExplored / NotAdjacent / InsufficientFunds）
     对应显示红色边框闪烁或提示文字
```

## 5. 清理与改造顺序

避免中间状态下出现视觉异常，建议按以下顺序处理：

1. **清理 AIEntityFactory**：删除 `SetActive(false)`（1a）
2. **清理 SyncCellObjectVisibility**：所有对象改为始终显示（1b）
3. **清理 SphereOfInfluenceRenderer**：删除 IsVisible 过滤（1c）
4. **清理 CameraController Canvas**：去掉探索条件（1g）
5. **清理 UIController 远程攻击指示器**：去掉 IsVisible 过滤（1h）
6. **改造河流 Shader**：删除 Alpha 消除 + 施加去饱和/薄雾（最显眼的消失问题）
7. **改造水面 Shader**：删除压暗 + 施加去饱和/薄雾
8. **改造 FogBlend.cginc**：`FogBlend_surf` 和 `FogBlend_final` 改为去饱和+半透明雾；删除 `FogBlend_shadowClip`
9. **清理 MapRenderer**：FogMask 上传去掉 FoV 依赖 + 顶点色 G 停止写入
10. **删除 IsVisible + FieldOfViewService + AIFogService**（阶段 6）

每步可独立提交 git，可回滚。
