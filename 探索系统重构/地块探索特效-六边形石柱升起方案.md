# 地块探索特效 —— 六边形石柱升起方案

## 效果目标

参考文明系列（Civ VI）风格：当某个地块从"未探索"变为"已探索"时，
一根深色石质六边形柱体从地面以下弹出，短暂遮住格子，随后从顶部向下溶解消散，露出真实地形。

---

## 项目参数确认

| 参数 | 值 | 来源 |
|---|---|---|
| 渲染管线 | Built-in RP | — |
| 格子朝向 | Pointy-top（第一个顶点在 +Z 方向） | `MeshDataGenerator.cs` 顶点生成逻辑 |
| OuterRadius | 3.0 | `MapGenerationConfigSO.OuterRadius` |
| SolidAreaRatio | 0.7 | `MapGenerationConfigSO.SolidAreaRatio` |
| 实心边界半径 | 3.0 × 0.7 = **2.1** | 计算值 |
| 每级高度世界单位 | 0.5 | `elevationStep` |
| 高度范围 | Height 0~5 → 世界 Y 0~2.5 | `HexCellData.Height` |

---

## 方案决策

| 环节 | 选择 | 理由 |
|---|---|---|
| Mesh 来源 | 代码运行时生成 | 半径精确对齐 2.1，不依赖外部资产 |
| 动画驱动 | Coroutine + AnimationCurve | 纯 Unity 原生，无需 DOTween |
| 升起方式 | Y 轴位移（非 ScaleY） | Pivot 在底面，比例不变形 |
| 消散方式 | Built-in Surface Shader Dissolve | Built-in RP 下最兼容的方案 |
| Dissolve 边缘 | **有发光效果**（emission 高光边） | 增加魔法感/碎裂质感 |
| 触发位置 | `FogManager.cs` 格子状态切换处 | 揭示逻辑集中在此 |

## 一、柱体 Mesh 设计

### 几何参数

- **外径**：2.1（= OuterRadius × SolidAreaRatio），贴合格子实心边界
- **高度**：1.5~2.0 世界单位（建议 1.8，视觉分量感足够）
- **Pivot**：底面中心，方便从地面以下弹出
- **朝向**：Pointy-top，第一个顶点对齐 +Z，与地图格子完全一致

### 顶点排列（复用现有逻辑）

```
顶面 6 顶点（顺时针，从 +Z 开始）：
  v0 = (0,   H, +r)
  v1 = (+i,  H, +0.5r)
  v2 = (+i,  H, -0.5r)
  v3 = (0,   H, -r)
  v4 = (-i,  H, -0.5r)
  v5 = (-i,  H, +0.5r)

底面 6 顶点（同上，Y=0）：
  v6~v11

侧面：6 个矩形 = 12 个三角形
顶面：1 个六边形 = 4 个三角形（扇形剖分）
底面：可省略（玩家看不见）

其中 r = 2.1（外径），i = r × 0.866025404（内径≈1.819）
H = 柱体高度（如 1.8）
```

### 实现建议

在 `ExplorationPillarMesh.cs`（新建）中用 `Mesh` API 运行时构建，
挂在 Prefab 的 `MeshFilter` 上，`Awake` 时生成一次，之后 Pool 复用。

## 二、动画设计

总时长约 **0.7 秒**，分三段：

```
阶段        时间区间      动画内容                           缓动曲线
──────────────────────────────────────────────────────────────────
升起        0.0s ~ 0.2s  Y 位移：cellY - 柱高 → cellY      OutBack（轻微弹跳感）
停顿        0.2s ~ 0.3s  静止不动
消散        0.3s ~ 0.7s  DissolveProgress: 0 → 1           Linear 或 EaseInCubic
```

### Coroutine 驱动示意

```csharp
IEnumerator PlayRevealAnimation(Vector3 cellWorldPos)
{
    // 1. 初始化位置（柱体在地面以下）
    transform.position = cellWorldPos + Vector3.down * pillarHeight;

    // 2. 升起阶段（0.2s，OutBack）
    float t = 0f;
    while (t < riseTime)
    {
        t += Time.deltaTime;
        float progress = riseEase.Evaluate(t / riseTime);   // AnimationCurve
        transform.position = Vector3.Lerp(
            cellWorldPos + Vector3.down * pillarHeight,
            cellWorldPos,
            progress);
        yield return null;
    }

    // 3. 停顿（0.1s）
    yield return new WaitForSeconds(holdTime);

    // 4. 消散阶段（0.4s）
    t = 0f;
    while (t < dissolveTime)
    {
        t += Time.deltaTime;
        float progress = t / dissolveTime;
        pillarMaterial.SetFloat("_DissolveProgress", progress);
        yield return null;
    }

    // 5. 回池
    ReturnToPool();
}
```

## 三、Dissolve Shader 设计（Built-in RP Surface Shader）

### 核心参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `_DissolveProgress` | Float [0,1] | 由 Coroutine 驱动，0=完整，1=完全消失 |
| `_NoiseTex` | 2D Texture | 灰度噪声贴图，控制溶解形状 |
| `_EdgeWidth` | Float | 发光边缘宽度（建议 0.05~0.1） |
| `_EdgeColor` | Color (HDR) | 发光边缘颜色（建议暖白/金色） |
| `_MainTex` | 2D Texture | 石头基础纹理 |

### 消散方向

**从顶部向下**：将顶点世界空间 Y 坐标归一化后混入阈值，
Y 越高越先被 `clip()`，视觉上石头从顶部开始崩碎。

### Shader 核心逻辑（伪代码）

```hlsl
// 在 surf 函数中：

// 采样噪声
float noise = tex2D(_NoiseTex, IN.uv_NoiseTex).r;

// 将世界 Y 坐标归一化（0=底部，1=顶部）
float normalizedY = saturate((IN.worldPos.y - _PillarBottomY) / _PillarHeight);

// 从顶部开始溶解：Y越高，cutoff越早触发
float cutoff = _DissolveProgress + normalizedY * 0.5;

// 裁剪（消失）
clip(noise - cutoff);

// 发光边缘：在即将被clip的薄层区域加 emission
float edgeMask = 1 - saturate((noise - cutoff) / _EdgeWidth);
o.Emission = _EdgeColor.rgb * edgeMask * _EdgeColor.a;  // HDR 颜色，a 通道控制强度

// 基础颜色
o.Albedo = tex2D(_MainTex, IN.uv_MainTex).rgb;
```

### 材质配置建议

- `_EdgeColor`：`(1.0, 0.85, 0.4, 3.0)` —— 暖金色，HDR 强度 3，有发光感
- `_EdgeWidth`：`0.08`
- `_NoiseTex`：使用 Unity 内置的 CloudsNoise 或导入一张 Perlin Noise 贴图
- 石头基础颜色：深灰带花纹，参考图里左侧柱体的石刻质感

## 四、触发位置

在 `FogManager.cs` 的格子状态切换逻辑中，当 `HexCell` 从
`Unexplored → Explored` 时调用：

```csharp
// 伪代码，位置待定
void OnCellRevealed(HexCellData cell)
{
    var pillar = explorationPillarPool.Get();
    pillar.Play(cell.CenterWorldCoordinate);
}
```

Pool 复用同一批 Prefab，避免频繁 Instantiate/Destroy。
