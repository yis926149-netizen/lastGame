## 二、缺失项清单（更新至 2026-08-02）

### P0 - 核心玩法

#### 1. 奖励 4 分类 + 开局预生成

**状态：⚠️ 部分实现（有偏差，以实际实现为准）**

策划案要求：对局开始时所有奖励地块预先确定"奖励倾向 + 具体奖励"；首次开发时只结算一次；已公开信息永久保留。

本项目已实现的方案（2026-08-02 两段式随机）：

- [x] ✔ **4 类奖励类型**：无奖励 / 金币 / 军事单位 / 战术卡牌，权重暴露于 `ExplorationRewardConfigSO`（默认 50/30/10/10，资产已写入）
- [x] ✔ **两段式随机**：第一次掷类型（`RollRewardType`），第二次掷具体值（`RollGold` / `RollUnitCount`+`RollUnitID` / `RollTacticalCard`）
- [x] ✔ **一格一次只给一种奖励**（替代原"金币+单位同时给"的双骰方案）
- [ ] ⚠️ **开局预生成未做**——已决策改为**开发时即时随机**（与策划案 §12 预生成不同，以实际实现为准；因此"奖励倾向公开机制"（见 P1-5）无法实现）
- [ ] ⚠️ **半场奖励总量一致未做**——即时随机无总量约束（策划案附录 D 要求，以实际实现为准）
- [ ] ❌ 石头桥面不参与奖励分配（需先有桥面地形类型，见 P2-10）

#### 2. 经济奖励 → 生成永久金矿

**状态：❌ 已决策移除（有偏差，以实际实现为准）**

策划案要求：经济奖励（30%）内部 50% 概率生成永久金矿。

本项目实现：**金币奖励为纯即时金币**（`goldTiers` 档位），不生成金矿；金矿保留为地图预置地貌（`LandFormEffectType.GoldIncomeBoost`），产金/断供暂停逻辑不变。

- [ ] ⚠️ 原待办（奖励生成金矿、金矿格禁部署）已取消，不实现

#### 3. 军事奖励 → 弱化援军

**状态：⚠️ 部分实现（有偏差，以实际实现为准）**

策划案要求：军事奖励（10%）生成一支弱化援军（50HP / 10ATK）。

本项目实现：

- [x] ✔ **军事奖励已实现**：`RollUnitCount` 数量 + `RollUnitID` 单位，溢出邻格（`SpawnUnitsWithOverflow`），玩家/AI 一致
- [ ] ⚠️ **弱化援军未做**——已决策生成**常规单位**（`rewardUnitIDs` 资产当前 {2,5}，Inspector 可调，以实际实现为准）

#### 4. 战术奖励 → 战术牌

**状态：✅ 已实现（2026-08-02）**

策划案要求：战术奖励（10%）获得一张战术牌，同名牌叠放数量。

- [x] ✔ `ExplorationRewardSystem` 注入 `TacticalCardPresenter`，`RollTacticalCard` 从 `TacticalCardDatabase` 随机抽维修/战斗号令
- [x] ✔ `TacticalCardPresenter.AddCard()`：同名牌 `Quantity++`、耗尽后重建视图、数量 >1 显示 "xN" 徽标
- [x] ✔ `ExplorationRewardConfigSO.asset` 已挂 `TacticalCardDatabase` 引用

### P1 - 关键行为偏差

#### 5. 奖励公开机制

**状态：❌ 未实现**

策划案要求：某一方连通领地第一次与奖励地块相邻时，该方可以看到"奖励倾向 + 开发价格"；已公开信息永久保留。

本项目现状：无"奖励地块"概念（开发时即时随机，无预生成数据可公开），开发价固定 50。此项受 P0-1"即时随机"决策影响，**确认不做**（以实际实现为准）。

#### 6. 开发"不处于交战状态"检查

**状态：❌ 未实现**

`ExplorationService.TryExplore` 只查邻接/金币/无敌方单位（`:53-55`），无交战判定。待办不变。

#### 7. 同时开发互斥

**状态：❌ 未实现**

玩家走 `ExplorationService`，AI 走 `AIAutoExplorer.cs:104-106` 直接改格子，未共用同一服务，存在同格双占风险。待办不变。

#### 8. AI 奖励与玩家不同步

**状态：✅ 已实现（2026-08-02）**

- [x] ✔ `AIAutoExplorer` 改走两段式结算：无奖励 / 金币→AI 钱包 / 军事→`AIEntityFactory` 生成（溢出邻格），与玩家共用同一套 `ExplorationRewardConfigSO` 掷骰
- [ ] ⚠️ 小偏差：**战术奖励 AI 暂不发放**（AI 战术牌系统未实现，日志提示），以实际实现为准
