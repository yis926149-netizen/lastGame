## 二、总体方案：数据修改 + 地形 mesh 全量重建

> 📌 2026-08-04 修订：本方案已升级为**通用分块重建管线**（`MapMutationService` + Chunk 渲染 + 动画），详见《动态地图/动态地图变化与分块重建方案.md》。本节的 `RebuildTerrain()` 描述为竞技场场景下的等价简化视图，实现时以分块方案为准。

- 地形合并 mesh 的过渡面片（slope/step、台阶细分）由**相邻两格高度差**决定，顶点数量随细分变化 → 合并 mesh 无法局部覆写 → **改高度必须全量重建地形 mesh**（`MapRenderer.cs:868-890`）。
- 推荐：把 `MapRender()` 中的创建流程（地形/河流/湖海/网格线/地貌资源模型）拆为可复用入口 `RebuildTerrain()`，跳过一次性初始化副作用（CostLabelRenderer、FogInit、FogEnvironmentSelectiveEffect.Initialize）。
- 局部重建（方案 B）不推荐：顶点数可变导致收益小、复杂度高。
- 性能量级：约千格地图全量重建 ≈ 数万顶点 + GC，单帧几十~两百毫秒；90 秒仅一次，可接受。

## 三、禁部署 = 以"不可探索"天然挡住（决策 2026-08-03）

**不新增任何部署校验代码**，利用部署前置条件（地块已探索）直接拦截：

- **预留区（开局~激活）**：`IsUnexplorable = true` → 不可探索 → 不可部署（既有机制，零新增）。
- **竞技场使用中**：内 2 环 + 边界环 `IsUnexplorable` 保持 true → 不可探索 → 不可部署。
- **宝箱摧毁后**：`IsUnexplorable = false` → 恢复可探索 → 自动恢复可部署/可占领。

### 3.1 迷雾消散改为"视觉强制点亮"（关键联动）

现有迷雾由 `MapRenderer.UpdateFogTransitionTargets` 按 `IsVisibleToFaction` 驱动（中立格 = 探索位）。若内部格不置探索位，迷雾会被过渡管理器拉回。

- **使用 `TemporaryVisibilityService` + Arena `VisibilityLease`**：突起时对 37 格申请 lease，统一 `IMapVisibilityResolver` 让地形/宝箱血条可见；阶段二同步刷新、阶段四可走过渡。
- **宝箱摧毁后释放 Arena lease → 迷雾重新遮盖**（第二轮确认）：探索位始终未置位，双方需自行探索恢复视野——"驱散"仅持续于竞技场使用期间。
- 优点：探索位保持干净，"未探索 → 不可部署"链条不被破坏；多个技能/事件可同时点亮同一格，释放 Arena lease 不影响其他来源。

### 3.2 与玩法文档 §6.1 的差异（已同步 2026-08-03）

- 玩法文档原状：内 2 环突起后"占领 ✅、迷雾 ✅ 消散"；宝箱摧毁后迷雾"保持已点亮"。
- 本决策：内 2 环突起后**不可探索/不可占领**（IsUnexplorable 保持 true），迷雾消散为视觉点亮（非探索位）；宝箱摧毁后**迷雾重新遮盖**（需探索恢复）。
- 已同步至玩法文档：§6.1 表"内 2 环"行占领列改 ❌；"全竞技场（宝箱摧毁后）"行迷雾列改"重新遮盖（需探索恢复）"；§6.2 说明补充"视觉点亮，不置探索位"；§十 决策 6/7 同步。

## 四、突起事件：数据修改清单（单帧完成）

1. **触发时机**（第二轮确认）：`ArenaActivateTime` 用 `GameLoop.GameTime` 自算——`状态=Reserved && GameTime ≥ 阈值` 时触发，**不挂 GlobalTimerService**（占用冲突见 §一）；GameTime 暂停冻结，海克斯暂停顺延（玩法文档 7.3）天然成立；0 = 开局即突起（初始化完成后立即触发）。
2. **中心格与 37 格列表**：开局按固定种子计算并缓存引用（由 ArenaEventManager 持有），运行时直接使用，不在突起瞬间现算。预留区开局标记：`IsUnexplorable = true` + 地面符文/光圈视觉标记（独立 root，FogAffectedEnvironment 层随迷雾雾化；突起时销毁，配置化 prefab）。
3. **内 2 环 19 格**：
   - `Height = ArenaFloorHeight`（配置，≥ seaLevel+1，自动脱离水域判定）
   - 清河流：`HexType = NoRiver`、hasRiver/出入方向清空
   - 清地貌/资源：`landForm/resource = null`，销毁模型，`LandFormMarkerManager` 浮标同步移除
   - `movementCost = 1`；`IsUnexplorable` 保持 true；可见性不写地块字段，由 Arena `VisibilityLease` 统一覆盖
   - 归属不写（保持中立）
4. **边界环 18 格（对称留 2 入口，入口格按普通地块）**：
   - `Height = ArenaWallHeight`（表现层墙高，配置）
   - `movementCost = float.MaxValue`
   - `IsUnexplorable = true`；可见性不写地块字段，由 Arena `VisibilityLease` 统一覆盖
5. **单位处理（决策 B）**：**先执行路径作废（见下），再统一扫描 37 格兜底弹射**（CancelMove 会把单位放回 StartHex，可能同样是不可通行格）——
   - 边界环格上单位 → 弹到最近可通行格：6 向 BFS 找 `movementCost < MaxValue` 且**无 Occupant** 的最近格；迁移 `SetHaveUnit`/`SetOccupant` + 刷新 transform.position + 释放攻击槽；**纯位置迁移**，不触发 TryCaptureEnemyCell、不写归属
   - 内环站立单位 → 仅刷新 y 到新 `RealCenterWorldCoordinate`
6. **路径作废**：
   - `GameLoop.InvalidateAllBrainPaths()`（公共建筑 Reveal 同款）
   - `UnitMovementSystem` 遍历移动任务：Path 途经 MaxValue 格 → 取消任务（CancelMove 回起点），由 Brain 按新地形重决策
7. **渲染**：`RebuildTerrain()` + `_mapVisualEvent.Raise()` + 特效/全图播报（复用现有特效池）
8. **费用标签**（2026-08-04 修订）：突起时入口格（2 格）、恢复时全竞技场——`CostLabelRenderer.RefreshLabels` **已支持动态创建/回收**（`CostLabelRenderer.cs:150-239`），无需新增补建机制；缺的是**重显标签时刷新 `_labelWorldPositions` 到新 `RealCenterWorldCoordinate`**（现有实现只 `SetActive(true)`，地块高度变化后标签会留在旧 Y，`:167-177`）。

## 五、宝箱摧毁后的恢复（纯规则恢复，零 mesh 重建）

> 触发：`CentralChest.OnDeath` 通知 ArenaEventManager 进入 Destroyed 后执行（§7.2）。

- **高度不回落**（决策）：不保存原高度快照，地形保持突起后的高地遗迹。
- 恢复内容：
  - 边界环 `movementCost = 1`
  - 全竞技场 `IsUnexplorable = false`（恢复可探索 → 自动恢复可部署/可占领）
  - **释放 Arena `VisibilityLease` → 迷雾重新遮盖**（探索位始终未置，双方需自行探索恢复视野；第二轮确认）
  - 费用标签补建（内部/边界格恢复可探索）
- `InvalidateAllBrainPaths` + `_mapVisualEvent.Raise()`。
- **无需 RebuildTerrain**（高度未变，地形网格不变）。

## 六、渲染拆解要点（RebuildTerrain）

- 从 `MapRender()` 抽出 5 个创建方法为可复用入口：地形 / 河流 / 湖海 / 网格线 / 地貌资源模型实例化。
- 跳过一次性初始化：CostLabelRenderer 创建、FogInit、SetupEnvironmentFogEffect。
- **替换语义（2026-08-04 修订）**：`CreatMesh` 替换 sharedMesh 后旧 mesh **并非可靠的"引擎自动回收"**——运行时 `new Mesh()`/`new Material()` 是引擎原生资源，不应依赖不确定的卸载时机；且 `CreatMesh` 每次新建大量独立材质（基础副本 + 双/三材质过渡实例，`MapController.cs:252-298`、`:332-422`），重复重建会持续泄漏 → **承载 GO 持久复用（`mesh.Clear()` 后重建）、材质按材质键缓存共享、独占运行时材质显式 `Destroy`**。河流/湖海承载 GO（"RiverWater"/"LakeOrSea"）与网格线同样持久复用，不反复新建销毁。
- 地貌/资源模型仅竞技场格销毁/重建（其余格不动，避免全图重实例化）。
- 迷雾顶点色随 FogAlpha 保留（数据在 HexCellData 上，重建自然带上）。

## 七、中央宝箱 = 公共建筑子类（决策 2026-08-03）

宝箱**实现为 `PublicBuildingBase` 子类**（`CentralChest`），不另建轻量组件；**不走** `PublicBuildingSO` 配置表/`PublicBuildingGenerator` 随机生成管线（生成时机、位置、随机性均不符）。

### 7.1 直接复用（零改动）

| 机制 | 代码 | 说明 |
|---|---|---|
| 受击入口 + 伤害公式 | `BuildingBase.BuildingAttacked` + `ComputeDamage`（含雕像/资源修正） | 与玩法"按现有公式结算"一致 |
| 最后一击判定 | `BuildingBase.Attacker`（受击入口记录最近攻击者） | 玩法 §5.1 所需，现成 |
| 血条 UI | `SpawnUIWiring.WireBuildingCanvas`（中立白） | — |
| 死亡驱动 | `GameLoop.RegisterPublicBuilding`（`CheckDeath` 已覆写为 currentHp≤0） | — |
| 海克斯触发 | `OnPublicBuildingCaptured` 事件，`TalentCardBootstrap` 已订阅 → RequestOffer | ⚠️ C# 事件只能由**声明类型内部** Invoke（`PublicBuildingBase.cs:29-30`），子类不能直接触发 → 需基类提供 `protected` 触发入口（§7.2-2/§7.3），链路零新增 |
| 摧毁后清格 | `PublicBuildingBase.OnDestroy`（publicBuildingRoot 清空 + movementCost=1f + BulidingType 清空） | "中心格恢复普通平地"现成 |

### 7.2 子类覆写（CentralChest : PublicBuildingBase）

1. **占格 1 格**：`Initialize` 传空 `subHexDirections` → OccupiedHexes 仅根格
2. **销毁结局**：覆写 `OnDeath`，不走 `OnCaptured`——直接：移除模型 + 触发海克斯 + 通知 ArenaEventManager 进入 Destroyed（执行 §五 恢复）。⚠️ 子类**不能直接** `OnPublicBuildingCaptured?.Invoke(...)`（事件仅声明类型内部可触发）→ 由基类新增的 `protected void RaiseCapturedEvent(int factionId)` 触发（§7.3），`TalentCardBootstrap` 已订阅、链路零新增
3. **始终中立**：`PlayerIndex = -1`，不注册 `PublicBuildingPlayerIndexes`、不扩势力范围
4. **直接出现**：生成即 active、`CurrentDiscoveryState` 置 Revealed，跳过 `TickDiscovery`/`Reveal`（`Reveal` 会写探索位，与迷雾视觉点亮方案冲突）。⚠️ `CurrentDiscoveryState` 为 `private set`（`PublicBuildingBase.cs:53`）、`TickDiscovery` 非 virtual（`:121`）——子类无法直接实现 → 基类提供 `protected` 状态入口（§7.3），宝箱**不注册发现 Tick**（仅注册死亡检测）或 `TickDiscovery` 改 virtual 由宝箱覆写为空
5. **单段血量**：`captureHp = 500`（不走易主，两阶段自然失效）

### 7.3 基类小改（2026-08-04 修订：由 1 处扩为 3 处）

1. `BuildingBase.RefreshHealthBarVisibility`（private，BuildingBase.cs:56）按 `IsVisibleToFaction` 判血条显隐——宝箱格中立+未探索 → 血条会被隐藏 → 改为统一查询 `IMapVisibilityResolver`（永久/后勤可见性 || 临时 VisibilityLease）
2. `PublicBuildingBase` 新增 `protected void RaiseCapturedEvent(int factionId)`——宝箱 `OnDeath` 经此触发海克斯（事件只能声明类型内部 Invoke，`PublicBuildingBase.cs:29-30`）
3. `PublicBuildingBase` 提供发现状态保护入口（如 `MarkRevealedWithoutExploration()`），`TickDiscovery` 改 virtual 或宝箱不注册发现 Tick（`CurrentDiscoveryState` 为 `private set`，`:53`）

### 7.4 索敌机制单独实现（不继承公共建筑索敌语义）

- 继承后宝箱默认被当"公共建筑/敌方建筑"索敌、且可能被箭塔锁定 → 索敌模块**单独设计**（另文）：宝箱识别（`is CentralChest`）、索敌链第二优先级（玩法 §4.2）、箭塔永远忽略（策划案 §21）。
- 涉及：`MeleeStrategy`/`RangedStrategy` 目标枚举加宝箱档位；`ArrowTowerShooter` 目标列表排除宝箱。
