# 箭塔建筑设计方案

## 一、设计

### 1.1 定位

箭塔是一种**自动防御建筑**，部署后定时搜索射程内的最近敌方单位并自动攻击。与军营（定时产兵）形成对称——军营进攻向外，箭塔防守向内。

### 1.2 参数

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 射程 | 2 环（18 格） | 两圈相邻格全覆盖，更符合"箭塔远程狙击"的定位 |
| 攻击间隔 | 3 秒 | 比军营（10 秒）快，弥补只出不进的特性 |
| 单次伤害 | 15（固定值） | 不参与 CombatResolver 加成公式，纯建筑自身输出 |
| 目标选择 | 射程内最近的敌方单位 | 简单直观，后续可改"血量最低" |
| 攻击目标类型 | 仅单位（Unit） | 不攻击建筑 |
| 归属 | 玩家与敌方均可部署 | 自动攻击对立阵营单位 |
| 初始解锁 | 是（`BaseBuildingIds`） | 开局即可抽到 |

### 1.3 与现有建筑的区分度

| 建筑 | 作用方向 | 触发方式 | 有无持续产出 |
|------|---------|---------|-------------|
| AttackStatue | 强化己方攻击 | 被动（战斗时查询） | 无 |
| DefenseStatue | 强化己方防御 | 被动（城市无敌判定） | 无 |
| Altar | 恢复己方 | Tick（站上去的人回血） | 无 |
| Barracks | 生成己方单位 | Tick（定时产兵） | 有 |
| **箭塔** | **削弱敌方单位** | **Tick（定时攻击）** | **无** |

箭塔填补了"自动伤害输出"这一缺口，是五个建筑中唯一能**独立对敌方造成伤害**的建筑。

### 1.4 动画表现

- 搜索到目标时，从箭塔位置向目标位置发射一个箭矢粒子特效
- 箭矢飞行时间约 0.2 秒，到达后消失
- 目标受击时播放通用的受击闪白或血条变化

## 二、实现

### 2.1 修改文件清单

| 文件 | 改动 |
|------|------|
| `Enums.cs` | `BulidingType` 枚举新增 `ArrowTower`（值=6，`Barracks` 之后、`PublicBuilding` 之前） |
| `CardUnlockRuleProvider.cs` | `BaseBuildingIds` 加入 `5`（buildingID），使箭塔进入抽卡池 |
| `BuildingDatabaseSO` 资产 | 需在 Inspector 中添加第 6 条数据（buildingID=5）：箭塔预制体、基础血量、卡牌 Sprite |
| `PlayerModelManager.cs` | 新增 `Index_ArrowTowerBuilding` 字典和 `ArrowTowerBuildingIndex` 计数 |
| `BuildingController.cs` | `RemoveFromPlayerBuildingIndexes` 新增箭塔清理 |
| `CardPresenter.cs` | `SpawnBuilding()` 的 switch 新增 `ArrowTower` case，挂载 `ArrowTowerShooter` 组件 |
| `AIEntityFactory.cs` | `GenerateBuilding()` 中判断 `ArrowTower`，挂载 `ArrowTowerShooter` 组件 |

### 2.2 新建文件

| 文件 | 路径 | 说明 |
|------|------|------|
| `ArrowTowerShooter.cs` | `Assets/Scripts/Controllers/` | 箭塔自动攻击组件 |

### 2.3 ArrowTowerShooter 核心逻辑

```
Update():
  ├── 暂停检查（GameLoop.IsPaused → return）
  ├── 计时器累积（Time.deltaTime）
  └── 计时器 >= 攻击间隔
        ├── 搜索 2 环（半径 2）内所有敌方格，再查询格上是否有敌方单位
        ├── 无敌人 → return（不扣计时器，下次即时重新搜索）
        ├── 找到 → 对目标单位扣血 15，同步血条
        ├── 检查目标死亡（CharacterData.currentHp <= 0 → 调用 UnitRemovalService 移除）
        └── 播放箭矢粒子特效（可选）
```

**注入依赖：**
- `IMapDataService` — 获取相邻格
- `GameLoop` — 暂停检测
- `IUnitRepository` — 查询相邻格单位
- `UnitRemovalService` — 目标死亡时移除单位

**注入方式：**
- 使用 Zenject 的 `[Inject]` 特性标注字段，与 `BarracksSpawner` 一致
- 在 `CardPresenter.SpawnBuilding()` 和 `AIEntityFactory.GenerateBuilding()` 中挂载组件后，调用 `_container.Inject(shooter)` 完成依赖注入

**不需要的依赖（与 BarracksSpawner 的区别）：**
- 不需要 `IUnitDataProvider`、`DiContainer`、`CombatResolver` 等完整生成管线
- 不需要创建新单位，只对已有单位扣血

### 2.4 攻击逻辑伪代码

```csharp
void TryShoot()
{
    HexCellData centerHex = 当前所在格;

    // 确定己方阵营
    int mySide = tag == "PlayerBuilding" ? 0 : 1;

    // 收集射程 2 环内的所有格子
    HashSet<HexCellData> cellsInRange = new HashSet<HexCellData>();
    cellsInRange.Add(centerHex);                       // 第 0 环
    for (int i = 0; i < 6; i++) cellsInRange.Add(相邻格(centerHex, i));  // 第 1 环
    
    HashSet<HexCellData> ring1 = new HashSet<HexCellData>(cellsInRange);
    foreach (var cell in ring1)
        for (int i = 0; i < 6; i++)
            cellsInRange.Add(相邻格(cell, i));         // 第 2 环

    // 搜索射程内最近的敌方单位（按六边形距离排序）
    CharacterData bestTarget = null;
    float bestDist = float.MaxValue;

    foreach (var cell in cellsInRange)
    {
        if (cell == null || cell.HexType == Enums.HexType.LakeOrSea) continue;
        遍历 cell 上所有单位 (via IUnitRepository);
        if (单位.阵营 != mySide)
        {
            float dist = HexDistance(centerHex, cell.HexCoordinate);
            if (dist < bestDist)
            {
                bestTarget = 该单位;
                bestDist = dist;
            }
        }
    }

    if (bestTarget != null)
    {
        bestTarget.currentHp -= 15;
        同步血条(bestTarget);
        if (bestTarget.currentHp <= 0)
            _unitRemovalService.RemoveUnit(bestTarget);
        PlayArrowEffect(bestTarget.model.transform.position);  // 可选
    }
}
```

### 2.5 与 Barracks 代码差异对比

| | BarracksSpawner | ArrowTowerShooter |
|------|------|------|
| 动作 | 生成新单位 | 攻击现有单位 |
| 注入数 | ~15 个 | ~4 个 |
| 单位创建 | 完整克隆 SpawnUnit 管线 | 不需要 |
| 阵营区分 | 生成时走不同管线 | 搜索时过滤敌对阵营 |
| 目标选择 | 最近空地 | 最近敌人 |
| 动画 | 无（后续可加） | 箭矢粒子特效 |

### 2.6 箭塔占用格

与普通建筑一致：部署时占据 1 个六边形地块，设置 `BulidingTypeOnHex_Building`，不可在其上布其他建筑或单位。地块移动开销保持默认 `1`（单位可穿过）。

### 2.7 测试检查点

1. 拖出箭塔卡牌部署后，Console 无报错
2. 敌方单位进入箭塔 2 环范围内后，3 秒内受到 15 点伤害
3. 箭塔只攻击 2 环内的目标，3 环外单位不触发
4. 目标单位血量归零后被正常移除（包括建筑索引清理）
5. 箭塔在不同阵营手中正确识别敌我
6. 游戏暂停时箭塔停止攻击
7. 城市易主时箭塔被正确摧毁并从索引中清理

### 2.8 存档/读档说明

项目当前无存档系统，箭塔的 `_timer` 计时器状态无需持久化。若后续增加存档功能，加载时计时器归零，等待一个完整攻击间隔后首次攻击即可，对体验无明显影响。

### 2.9 资产配置确认

- **buildingID = 5**：对应 `BuildingDatabaseSO` 中索引为 5 的条目
- **枚举值 = 6**：`Enums.BulidingType.ArrowTower = 6`（计算公式：buildingID + 1）
- 需在 Unity Inspector 中为 `BuildingDatabaseSO` 补充第 6 条数据（索引 5）：
  - `buildingModels[5]`：箭塔预制体
  - `buildingBaseHP[5]`：基础血量（建议 100）
  - `buildingCards[5]`：箭塔卡牌 Sprite
