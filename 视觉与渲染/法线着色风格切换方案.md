# 法线/着色风格切换方案

## 概述

在 `MapGenerationConfigSO` 的 Inspector 面板中新增下拉框，提供 **6 种不同渲染风格**，通过控制过渡面是否使用 Flat Shading 以及法线后处理来产生不同视觉效果。切换风格后重新进入 Play 模式即可直观对比。

---

## 涉及文件

| 文件 | 改动类型 | 说明 |
|---|---|---|
| `Assets/Scripts/Utilities/Enums.cs` | 新增枚举 | 定义 `ShadingStyle` |
| `Assets/Scripts/ScriptableObjects/MapGenerationConfigSO.cs` | 新增字段 | Inspector 下拉框入口 |
| `Assets/Scripts/Managers/MapRenderer.cs` | 条件分支 + 后处理 | 修改过渡面风格控制 + 法线后处理 |

---

## 6 种风格定义

| # | 枚举名 | 名称 | 矩形 FlatShading | 三角 FlatShading | 法线后处理 | 视觉特征 |
|---|---|---|---|---|---|---|
| 1 | `FlatAll` | 当前（全部硬边） | ✅ | ✅ | 无 | 全部硬边，三角轮廓明显 |
| 2 | `SmoothAll` | 全平滑 | ❌ | ❌ | 无 | 全平滑，Unity 自动平均法线；三角扇形中心可能偏暗 |
| 3 | `FlatRect_SmoothTri` | 矩形硬·三角软 | ✅ | ❌ | 无 | 矩形斜面硬边，三角角落平滑 |
| 4 | `SmoothRect_FlatTri` | 矩形软·三角硬 | ❌ | ✅ | 无 | 矩形斜面平滑，三角角落硬边 |
| 5 | `ForceUpNormals` | 侧面法线向上 | ❌ | ❌ | 侧面法线强制设为 `Vector3.up` | 斜面不产生侧面暗区，整体偏平；适合卡通/低多边形感 |
| 6 | `ExaggeratedNormals` | 侧面法线夸张 | ❌ | ❌ | 侧面法线水平分量放大、Y 压缩后重归一化 | 斜面阴影更强烈、边缘更戏剧化 |

## 核心控制点

### 1. 矩形过渡 Flat Shading
`MapRenderer.cs` `MainMapMeshCreat()` 第 206 行：
```csharp
RectangleTransitionMeshData flatRectangle = RectangleTransitionMesh.ToFlatShaded(rectangle);
```
改为条件判断，仅在需要时调用。

### 2. 三角过渡 Flat Shading
`MapRenderer.cs` `GetGenericTriangleMesh()` 第 767、775 行：
```csharp
return TriangleTransitionMesh.ToFlatShaded(RectangleDrivenTriangleMesh.BuildNEE(...));
```
改为条件判断，仅在需要时调用。

### 3. 平滑法线与风格后处理
在 `MapRenderer.cs` `MainMapMeshCreat()` 末尾，对返回 mesh 的法线进行处理。需要注意：`Mesh.RecalculateNormals()` 只会平均共享同一顶点索引的面；本项目的实心区、矩形过渡和三角过渡是分批追加的，空间位置相同但索引不同。因此平滑风格必须按量化后的世界位置聚合面积加权面法线，再写回所有重合顶点。

完成法线写回后重新计算切线，并复用 `MapController` 的 NaN/Inf 清理逻辑，确保法线贴图的切线空间有效。

- 风格 5：将所有已记录的过渡面顶点法线设为 `Vector3.up`，消除侧面阴影。
- 风格 6：将所有已记录的过渡面法线水平分量 ×2、Y 分量 ×0.3 后归一化，让侧面向外倾斜，增大光照对比。

## 实现细节

### `Enums.cs` 新增
```csharp
public enum ShadingStyle
{
    FlatAll,              // 1 - 当前：矩形+三角均 flat
    SmoothAll,            // 2 - 全平滑
    FlatRect_SmoothTri,   // 3 - 矩形平坦，三角平滑
    SmoothRect_FlatTri,   // 4 - 矩形平滑，三角平坦
    ForceUpNormals,        // 5 - 侧面法线朝上
    ExaggeratedNormals    // 6 - 侧面法线夸张
}
```

### `MapGenerationConfigSO.cs` 新增字段
```csharp
[Header("法线/着色风格对比")]
[Tooltip("切换后重新进入 Play 模式即可对比不同渲染风格")]
public Enums.ShadingStyle shadingStyle = Enums.ShadingStyle.FlatAll;
```

### `MapRenderer.cs` 条件判断
```csharp
static bool RectFlat(Enums.ShadingStyle s) =>
    s == Enums.ShadingStyle.FlatAll || s == Enums.ShadingStyle.FlatRect_SmoothTri;

static bool TriFlat(Enums.ShadingStyle s) =>
    s == Enums.ShadingStyle.FlatAll || s == Enums.ShadingStyle.SmoothRect_FlatTri;
```
矩形过渡和三角过渡分别按上述函数判断是否调用 `ToFlatShaded()`。

### 法线后处理方法
```csharp
private void PostProcessNormals(Mesh mesh, Enums.ShadingStyle style)
{
    if (style != Enums.ShadingStyle.ForceUpNormals &&
        style != Enums.ShadingStyle.ExaggeratedNormals) return;

    Vector3[] normals = mesh.normals;
    for (int i = 0; i < normals.Length; i++)
    {
        if (normals[i].y >= 0.85f) continue;

        normals[i] = style == Enums.ShadingStyle.ForceUpNormals
            ? Vector3.up
            : new Vector3(normals[i].x * 2f, normals[i].y * 0.3f, normals[i].z * 2f).normalized;
    }
    mesh.normals = normals;
}
```

## 注意事项

1. **不删除旧代码**：`ToFlatShaded()` 方法本身保留不动，仅在调用处加条件。
2. **后处理顺序**：`MapController.CreatMesh()` 内部已经调用 `RecalculateNormals()` + `SanitizeNormalsAndTangents()`，后处理在返回的 mesh 上追加，NaN/Inf 已被清理过。
3. **影响范围**：仅地形主网格（`_terrainMesh`），不涉及河流、水面、网格线。
4. **`_config` 访问**：`MapRenderer` 已通过 `[Inject]` 注入 `MapGenerationConfigSO _config`，所有私有方法可直接访问。
5. **使用流程**：在 `MapGenerationConfigSO` 资源 Inspector 中选风格 → 进入 Play 模式 → 观察 → 退出 → 换风格 → 再进入 Play。
